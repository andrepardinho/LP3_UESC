# Linguagem de Programação III

Repositório dedicado aos exercícios e práticas da disciplina **Linguagem de Programação III** do curso de **Ciência da Computação** - UESC.

## 📌 Objetivo da Disciplina

A disciplina tem como foco principal o estudo e a aplicação dos conceitos de **Programação Orientada a Objetos (POO)**, abordando princípios fundamentais como:

- Objetos e classes;
  - Instâncias;
  - Atributos;
  - Métodos;
  - Encapsulamento e ocultamento da informação;
- Agregação;
- Generalização/especialização e Herança;
- Polimorfismo;

## 🛠️ Tecnologias e Linguagens

- [`JAVA`](https://github.com/andrepardinho/LP3_UESC/tree/java) ☕  
- [`PYTHON`](https://github.com/andrepardinho/LP3_UESC/tree/python) 🐍

## 📂 Conteúdo do Repositório

- Exercícios práticos de POO  
- Implementação de projetos aplicando os princípios da orientação a objetos  
- Exemplos de código em Java e Python
